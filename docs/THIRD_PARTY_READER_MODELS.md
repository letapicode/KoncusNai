# Third-party reader models

## AI4Bharat Indic Parler-TTS

Koncus Nai can download and use `ai4bharat/indic-parler-tts` for optional local narration in 21
officially supported languages and three upstream-described experimental languages. The model
checkpoint and `parler-tts` implementation are published under Apache License 2.0. Copyright
and attribution remain with AI4Bharat, the Parler-TTS authors, and their contributors. Model
weights are gated and are downloaded only after the user accepts the upstream access terms.
Generated voice previews are not distributed. Users generate previews locally
after downloading and accepting the relevant model terms. Speaker,
training-data, and generated-output provenance still matters to each user's use.

- Model and language/speaker documentation: https://huggingface.co/ai4bharat/indic-parler-tts
- Implementation: https://github.com/huggingface/parler-tts
- License: https://www.apache.org/licenses/LICENSE-2.0

## Kala Nepali TTS v0.2

Koncus Nai can download and use `ampixa/real-nepali-v0.2-kala` for optional local Nepali narration.
The `kala-tts` PyPI package labels its code MIT. The pinned model card labels its model weights/code and listed training corpus CC BY-SA 4.0, and its G2P lexicon seed CC BY 4.0. These are separate upstream materials; copyright and attribution belong to Ampixa and the respective contributors. Ampixa replied to the owner's question about generated and commercial use of the listed voices as recorded in the [owner decision record](release/public-source-owner-decision-record.md).

- Model: https://huggingface.co/ampixa/real-nepali-v0.2-kala
- Python package: https://pypi.org/project/kala-tts/
- Model license: https://creativecommons.org/licenses/by-sa/4.0/
