# Koncus Nai project-license decision

Status: **owner decision recorded on September 21, 2026**.

This decision concerns only code and original assets owned by the Koncus Nai
copyright holder. Models, packages, fonts, runtimes, and other third-party
materials retain their own licenses; see `MODEL_LICENSES.md` and
`THIRD_PARTY_NOTICES.md`.

## Option A: GPL-3.0-or-later plus separate commercial licenses

- Anyone may run, inspect, modify, redistribute, and sell GPL copies.
- Anyone distributing a modified or compiled GPL version must satisfy the GPL,
  including corresponding-source requirements.
- The copyright owner may separately sell a commercial license for original
  Koncus Nai code when the owner retains the necessary copyrights.
- Contributions need an owner-approved contributor agreement if future dual
  licensing must remain possible.
- This is an open-source option. It does not reserve resale exclusively to the
  original author.

## Option B: PolyForm Noncommercial 1.0.0 source-available license

- [PolyForm Noncommercial 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0/)
  is an established, published license text that permits the noncommercial and
  specified personal uses defined in its terms.
- Uses outside those permitted purposes require a separate license from the
  copyright owner, so the owner can offer commercial terms for code the owner
  controls.
- Companies and commercial deployments would need separate permission under
  those terms unless their use falls within an express permitted-purpose
  category.
- This is source available, not open source, because an open-source license may
  not prohibit commercial use or resale.
- PolyForm's definitions may be broader or narrower than the owner's intended
  policy in specific situations. The owner should have counsel confirm the fit
  before publishing it. The project must not edit the standard text or publish
  an AI-authored custom license as though it were established legal text.
