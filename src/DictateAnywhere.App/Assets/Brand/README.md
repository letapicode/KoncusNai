# Koncus Nai brand assets

Approved direction: folded KN monogram, burnt orange #D85A2A and shadow #A83C1C.
The editable SVG master and custom outlined lettering are reconstructed for production from the approved concept; no font is required by the SVG wordmarks.
Regenerate with `powershell.exe -NoProfile -STA -File scripts/generate-koncus-nai-icons.ps1`.
Nine transparent ICO/PNG sizes cover 16 through 256 pixels; WPF uses the same geometry and inherits monochrome high-contrast text ink.
Nilo.ico and ../Notype.ico are generated compatibility aliases for existing pins.
The generated concept board is a design reference, not the executable icon.
